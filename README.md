## 🏛️ The Five SOTA AI Workbenches

### 1. 🤖 AgentCraft: Swarm DAG Orchestrator
- **Concept:** Enterprise Agentic Workflow Engine inspired by LangGraph, CrewAI, and AutoGen.
- **Features:**
  - Dynamic Intent Decomposition into parallel DAG nodes.
  - Live ReAct cognitive execution stream (`Thought -> Action -> Observation`).
  - High-performance Python pipeline synthesis with automated typing and dataclasses.
  - Interactive In-Browser Sandbox Terminal Emulator (`▶️ Run in Sandbox`) and quick copy button.
  - 60 FPS HTML5 Canvas DAG communication visualizer.

### 2. 🧠 NeuraForge: LLM & Attention Foundry
- **Concept:** Parameter-Efficient Fine-Tuning (PEFT) and Transformer Self-Attention Mechanics.
- **Features:**
  - Interactive Low-Rank Matrix Decomposition ($W = W_0 + \frac{\alpha}{r} B \cdot A$).
  - Dynamic sliders for LoRA Rank ($r$) and Alpha ($\alpha$) recalculating trainable parameters and memory savings in real time.
  - Dynamic Scaled Dot-Product Attention matrix ($\text{Softmax}(Q \cdot K^T / \sqrt{d_k}) \cdot V$) computed live for any user-typed sentence across 4 specialized attention heads.
  - Interactive training mode simulator (SFT with LoRA, DPO Alignment, Causal Pre-Training) updating live loss curves.

### 3. 📊 PulseML: AutoML & Explainable AI
- **Concept:** Automated Machine Learning and SHAP (SHapley Additive exPlanations) Engine.
- **Features:**
  - Algorithmic Leaderboard comparing XGBoost, LightGBM, Random Forest, and MLP.
  - Bivariate Pearson Correlation Matrix (6×6) with clean mathematical formatting.
  - Real-Time Decision Threshold ($\tau$) slider dynamically updating Confusion Matrix counts (TP, FP, FN, TN) and F1-Score.
  - Interactive SHAP Waterfall Plot recalculating predicted fraud probabilities and waterfall bar lengths as features are tuned.

### 4. 👁️ OmniVision: Real-Time Multimodal Lab
- **Concept:** Real-Time Computer Vision and Zero-Shot Foundation Model Studio.
- **Features:**
  - 60 FPS HTML5 Canvas simulated sensor stream with synthetic tracked targets.
  - YOLOv8 Object Detection with futuristic corner brackets, class labels, and confidence tags.
  - Interactive Confidence Threshold slider ($0.10 \le \text{conf} \le 0.95$) filtering detections in real time.
  - Zero-Shot CLIP Image-Text Embedding matching: enter natural language prompts to calculate cosine similarity against visual objects.
  - Grad-CAM neural attention saliency heatmap overlay toggle.

### 5. 🛡️ CyberRadar: Autonomous AI SOC
- **Concept:** AI-Driven Security Operations Center and Threat Mitigation Radar.
- **Features:**
  - 360-degree rotating radar canvas with concentric range rings and animated vector attack trajectories.
  - MITRE ATT&CK® matrix coverage tracker across tactics (Initial Access, Execution, Persistence, Defense Evasion, C2).
  - AI Anomaly Detection Score threshold slider (Autoencoder + Isolation Forest).
  - SIEM incident triage table with autonomous containment playbooks (Host Isolation via eBPF, BGP Blackhole routing).
